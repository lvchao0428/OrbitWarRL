Orbit Wars top-10% daily episode replay datasets
I've published a per-day series of replay datasets covering Orbit Wars, one dataset per UTC day from 2026-04-16 through 2026-05-04. Each dataset contains the highest-quality matchups of that day - useful for opponent analysis, imitation learning, or just spectating top-of-leaderboard play.

Methodology
For each UTC day:

Query for every Orbit Wars episode created that day.
For each episode, sum both agents' post-episode rating (UpdatedScore). This biases toward matchups where strong bots played strong bots.
Keep the top 10% of episodes by that summed rating.
Download replay JSONs in priority order (highest sum first).
Stop as soon as the next replay would push the total over 20 GiB (most days are well under).
Bundle the chosen replays and publish.
Each dataset contains:

episodes.tar.gz — the replay JSONs, extracts to episodes/{episode_id}.json
manifest.csv — episode_id, create_time, sum_score, min_score, avg_score, scores, submission_ids, size_bytes (in priority order)

Use it in a Kaggle notebook
Add the dataset(s) you want via + Add Data → search orbit-wars-top10-episodes. Each one mounts at /kaggle/input/<dataset-slug>/.

import csv, json, tarfile
from pathlib import Path

DAY = "2026-05-04"
ROOT = Path(f"/kaggle/input/orbit-wars-top10-episodes-{DAY}")

# Manifest: one row per episode, in priority (highest sum_score first)
with (ROOT / "manifest.csv").open() as f:
    manifest = list(csv.DictReader(f))
print(f"{len(manifest)} episodes; top sum_score = {manifest[0]['sum_score']}")

# Stream replays straight out of the tarball — no need to fully extract
with tarfile.open(ROOT / "episodes.tar.gz", "r:gz") as tar:
    for row in manifest[:5]:
        member = tar.getmember(f"episodes/{row['episode_id']}.json")
        replay = json.load(tar.extractfile(member))
        # ... do something with `replay` ...
Download with the Kaggle CLI
pip install kaggle  # if needed; ensure ~/.kaggle/kaggle.json is set up

kaggle datasets download bovard/orbit-wars-top10-episodes-2026-05-04 --unzip
tar -xzf episodes.tar.gz   # extracts to episodes/{episode_id}.json
Or grab the whole series:

for d in 2026-04-{16..30} 2026-05-{01..04}; do
  kaggle datasets download "bovard/orbit-wars-top10-episodes-$d" --unzip -p "$d"
done
